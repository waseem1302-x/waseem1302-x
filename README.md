## 🚀 What I'm Building Now

### The Next Scholar (Flagship Project, In Progress)

A scholarship platform at [thenextscholar.com](https://thenextscholar.com) for students across Asia and Africa. I built it because I faced this problem myself: finding a real, verified scholarship, with the right deadline and the right eligibility, is hard. I am building it so other students do not face the same problem, and so people can see I am a real problem solver.

- Source-first deterministic matching with proper reasons, hard eligibility rules first
- Citation-first RAG assistant that abstains when it has no evidence
- FastAPI, PostgreSQL, React/TypeScript
- Launch scope: 21 scholarship families, verified one by one against official pages

### Production RAG with Eval Harness (Built)

A small, honest, production-shaped RAG system over 19 official scholarship pages, with a measured eval harness.

- Corpus: 19 documents, 101 chunks (512 tokens)
- Golden set: 50 questions (43 in corpus, 7 out of corpus, 11 eligibility)
- Answer-only relevance 0.907, recall@5 1.0, faithfulness 1.0, abstention 1.0, eligibility 1.0
- 179 tests passing, cost $0.00 per query (local CPU, no API calls)
- Opt-in generative answer with local Qwen2.5-0.5B-Instruct, verified sentence by sentence
- Repo: [waseem1302-x/production-rag-eval-harness](https://github.com/waseem1302-x/production-rag-eval-harness)
